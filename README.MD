# EmployeeApp (MEVN Learning Project)

## Why I built this

I’m a **.NET (C#) developer** and I wanted a fun, practical way to learn a new stack — specifically **Node.js + Express + MongoDB + Vue**.

This project is a playground for me to:
- sharpen up my **Node.js backend skills**
- get more exposure to **frontend development with Vue**
- apply the same “strong API” mindset I’ve built in C# (clean structure, good practices, maintainable code) to **JavaScript**
- enjoy the flexibility of JavaScript while still keeping the **order and structure** I like from .NET

## What I hope to achieve

### Backend goals
- Build a clean, maintainable API using:
  - controllers / routes / services separation
  - authentication & authorization (JWT)
  - solid error handling patterns
  - consistent API responses
- Get comfortable writing Node.js code with an “API-first” mindset

### Frontend goals
- Build a Vue UI that:
  - supports login/logout
  - protects routes when unauthenticated
  - performs CRUD for employees
  - reuses components (shared forms, cards, etc.)

### Cloud goals (AWS)
I come from an **Azure background**, so I’ll also be exploring **AWS** with this project to learn how AWS services fit into a real application.

Planned areas to explore:
- deployment (frontend + backend)
- secrets/config management
- hosting and monitoring basics
- learning the “AWS way” of doing things vs Azure equivalents

## Tech stack
- **Backend:** Node.js, Express, MongoDB (Mongoose)
- **Frontend:** Vue + Vite
- **Auth:** JWT-based authentication & role authorization

## Getting started

### Backend
```bash
cd backend
npm install
npm run dev
```

### Frontend
```bash
cd frontend/employee-ui
npm install
npm run dev
```
